## 2024-05-23 - Webhook Fails Open on Missing Secret
**Vulnerability:** The `payment-webhook` function at `supabase/functions/payment-webhook/index.ts` was designed to skip signature verification if the `LENCO_WEBHOOK_SECRET` environment variable was not set. This created a "fail-open" scenario where the webhook would process unverified, potentially malicious requests in a misconfigured environment.
**Learning:** A missing secret in a security-critical function like a webhook handler must never result in a permissive fallback. The default behavior must always be to "fail-secure" by rejecting the request. The original code treated the absence of a secret as a development convenience, but this is a critical security anti-pattern that can be exploited in production if the secret is not deployed correctly.
**Prevention:** All webhook handlers in this project must be audited to ensure they strictly enforce signature verification. Any new webhooks must be implemented to fail securely if a verification secret is missing. I will make this a priority check during future security scans.
